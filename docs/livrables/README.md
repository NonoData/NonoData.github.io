# Livrables à ajouter

Déposer ici uniquement les documents destinés à être accessibles publiquement depuis le portfolio.

Exemples de noms de fichiers :

```text
analyse-besoin-metier.pdf
cahier-des-charges.pdf
documentation-power-bi.pdf
```

Ensuite, utiliser un lien relatif dans `docs/index.html` :

```html
<a href="livrables/cahier-des-charges.pdf" target="_blank">Voir le cahier des charges</a>
```

Avant publication :

- vérifier l’anonymisation des données ;
- supprimer toute information confidentielle ;
- utiliser des noms de fichiers sans espaces ni accents ;
- ouvrir chaque lien pour vérifier son fonctionnement.
